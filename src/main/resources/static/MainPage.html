Raw Execution Plan

        

        

            

                 용어 가이드 (핵심 5가지)
            

            

                

                    1. Node Type

                    데이터를 찾는 '방식'입니다. 

                    - Index Scan: 인덱스로 바로 찾기 (빠름)

                    - Seq Scan: 처음부터 끝까지 다 읽기 (느림)
                

                

                    2. Total Cost

                    DB가 예상한 전체 '비용'입니다. 숫자가 낮을수록 서버에 부담이 적은 효율적인 쿼리입니다.
                

                

                    3. Actual Total Time

                    실제 실행에 걸린 '진짜 시간'입니다. 

                    - 10ms 이하: 매우 빠름

                    - 100ms 이상: 최적화 고민 필요
                

                

                    4. Shared Hit

                    '메모리(RAM)'에서 바로 찾은 횟수입니다. 이 숫자가 높을수록 디스크를 안 거쳐서 속도가 폭발적으로 빨라집니다.
                

                

                    5. Planning Time

                    DB가 최적의 길을 찾기 위해 '고민한 시간'입니다. 쿼리가 복잡할수록 이 시간이 늘어납니다.
